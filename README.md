## Projeto Calculadora De Combustível

O Aplicativo tem como funcionalidade de calcular:

° A distancia de uma viagem
° O Consumo medio por litro (km/L)
° O Valor do preço de combustível 



Com base nesses dados o aplicativo calcula quanto de combustivel sera gasto e o custo total da viagem.



## Tecnologias e conceitos utilizados

° kotlin
° Activities 
° UI com xml 
 °TextView
 °EditText
 °Button
° Navegaçao entre telas 
° Toolbar
° Organização básica de layouts
